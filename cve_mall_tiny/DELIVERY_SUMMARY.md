## 五、当前 CVE 申请就绪性

### 最终结论

当前 mall-tiny 验证码问题的 CVE 申请就绪性：**Need more evidence**

当前置信度：**Medium**

### 尚未满足的条件

1. ❌ 受影响代码存在于正式发布版本或明确可引用的 tag/commit 中
2. ❌ `/sso/getAuthCode` 未认证可访问，或攻击前提清晰
3. ❌ 验证码明文返回得到动态测试证明
4. ❌ `verifyAuthCode` 或业务流程使用该验证码
5. ❌ `register`/`login`/`updatePassword` 中至少一个敏感流程受到实际影响
6. ✅ 不是重复 CVE（已确认）
7. ⚠️ 修复建议可行（patch 已编写，待验证编译）
8. ❌ PoC 能复现安全影响，而不是仅演示 Random 原理

### 下一步建议

1. **短期 (1-2周)**: 搭建完整测试环境，完成动态测试
2. **中期 (2-4周)**: 通过 GitHub Security Advisory 联系项目维护者
3. **长期 (3-6月)**: 根据维护者反馈决定是否正式申请 CVE
